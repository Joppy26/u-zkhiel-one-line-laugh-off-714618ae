An entry for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) competition on make.fun.

## What it does

`main.py` writes exactly one original joke — a single funny line, no setup notes, no explanation — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default).

## Run it

```sh
python3 main.py
```

The output is deterministic: every run writes the same line, byte for byte.
